# Learning Playground

This is the sandbox. Try ideas, build little prototypes, and break things here
without getting in the way of the main protocol code.

## How to use it

Give each experiment its own folder so the code and build output stay together:

```text
learning/
`-- my-experiment/
    |-- README.md
    |-- main.c
    `-- build/
```

Experiments do not need to join the main build or tests. Leave a small
`README.md` with the command to run yours and anything people should know. If
an idea becomes solid and useful, move it into the right project directory and
add proper tests and docs.
